# Dash Documentation

**[Dash](https://dashblocks.github.io/)** is based on **[TurboWarp](https://turbowarp.org/)** and adds stuff like **JSON category**, **console mode**, **new blocks**, **extensions**, **editor customization**, and **other features**. This is the place where its extra documentation goes.

Related projects:

 - [Dash Desktop](https://dashblocks.github.io/desktop/)
 - [Dash Packager](https://dashblocks.github.io/packager/)
 - [Dash Unpackager](https://dashblocks.github.io/unpackager/)
 - [Dash Extension Gallery](https://dashblocks.github.io/extensions/)

These pages are [open source](https://github.com/DashBlocks/docs). Contributions are welcome.
